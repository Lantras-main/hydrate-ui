Overview

Hydrate is a straightforward Lua UI library designed for Roblox scripts. It's built with pure black-and-white aesthetics, smooth tweening animations, and a multi-column section setup so your script menus stay clean and organized.

Setup

Load the script via standard HttpGet and pass your main window title into the constructor.

local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/Lantras-main/hydrate-ui/refs/heads/main/main.lua"))()

local Window = Library.new("My Script Window")

Layouts & Tabs

Create tabs to house your interface categories, then add sections to either the left or right column.

local MainTab = Window:AddTab("Main")

local LeftCol = MainTab:AddSection("left", "Player Settings")
local RightCol = MainTab:AddSection("right", "Visual Toggles")

Elements Reference

Full breakdown of all element methods available on a section object.

Method Name Arguments Details
AddButton name, callback Fires a brief highlight animation on click.
AddToggle name, default, callback Checkbox toggle. Returns object with :Set(bool).
AddSlider name, min, max, default, precise, callback Draggable slider. Pass true to precision decimals. Returns :Set(val).
AddDropdown name, list, default, callback Dropdown list with smooth dropdown scaling animations.
AddTextbox name, placeholder, callback Input box triggering on focus loss or enter press.
AddKeybind name, defaultKey, callback Binds a key and listens for changes on the fly.
AddLabel text Static text row. Returns object with :Set(text).

Quick Example

A sample snippet showing how everything hooks together in practice.

local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/Lantras-main/hydrate-ui/refs/heads/main/main.lua"))()

local Window = Library.new("Test Hub")
local Tab = Window:AddTab("Combat")
local Sec = Tab:AddSection("left", "Aimbot")

Sec:AddToggle("Enabled", true, function(state)
    print("Aimbot:", state)
end)

Sec:AddSlider("FOV", 50, 300, 100, function(value)
    print("FOV size:", value)
end)
